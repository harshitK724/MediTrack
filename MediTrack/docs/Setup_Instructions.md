# Setup and Installation Guide

### Prerequisites
- **JDK:** Version 11 or higher must be installed.
- **Environment Path:** `JAVA_HOME` should be configured in your system variables.
- **IDE:** Visual Studio Code with the "Extension Pack for Java".

### Installation Steps
1. [cite_start]**Clone/Download:** Ensure the project folder structure matches the `com.airtribe.meditrack` package path[cite: 8].
2. **Open in VS Code:** Use the command `code .` in your terminal or open the folder manually.
3. **Verify Extensions:** Ensure the Java Language Support is active.

### Running via Terminal (macOS/Linux)
From the root directory `MediTrack/`:

**1. Compile the Project:**
